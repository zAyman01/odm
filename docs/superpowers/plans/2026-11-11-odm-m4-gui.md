# odm M4: GUI Desktop Client — Implementation Plan

> **For agentic workers:** Do the tasks in order, one at a time, every step in order. Tick each checkbox as you finish it. If a command's output does not match the "Expected" line, stop and report; do not work around it.

**Goal:** Build the desktop client (`odm-gui`) in Rust using `eframe`/`egui` with a reactive view-state architecture, top toolbar controls, left filter/queue sidebar, download table with progress bars, segment visualizer detail panel, add download dialog with URL probing, settings dialog, clipboard URL monitoring, completion notifications, and system tray integration.

**Milestone Success Criterion:** Downloads managed from the window (verified through headless view-state & bridge integration tests plus a comprehensive repository manual checklist).

**Architecture:**
- `odm-gui::state`: Pure view-state models (`ViewState`, `Filter`, `AddDialogState`, `SettingsDialogState`, `ThemeMode`). Contains pure transition reducers (`apply_event`, `filtered_downloads`) decoupleable from rendering, enabling 100% testable GUI logic.
- `odm-gui::messages`: Strongly typed `UserAction` (dispatched from UI to bridge) and `GuiEvent` (streamed from background bridge to UI).
- `odm-gui::bridge`: Background Tokio worker that ensures `odm-daemon` is running, maintains the `/api/v1/events` WebSocket stream, and executes asynchronous REST operations without ever blocking the UI thread.
- `odm-gui::desktop`: Clipboard monitoring (`arboard`) detecting copied URLs and desktop notifications (`notify-rust`) on job completion or failure.
- `odm-gui::ui`: Componentized immediate-mode GUI (`toolbar`, `sidebar`, `downloads_table`, `detail_panel`, `add_dialog`, `settings_dialog`) rendered via `eframe::App`.
- `docs/manual-checklists/m4-gui.md`: Step-by-step verification checklist for manual visual and interaction testing.

**Spec:** `docs/superpowers/specs/2026-11-11-odm-design.md` (sections 2, 5.3, 6, 7, 8 and milestone M4 in section 12).

```rust
    state.apply_event(GuiEvent::EngineEvent(Event::JobProgress {
        id: 10,
        downloaded_bytes: 800 * 1024,
        total_bytes: Some(1024 * 1024),
        speed_bps: 256 * 1024,

    assert_eq!(state.downloads[0].downloaded_bytes, 800 * 1024);
    assert!((state.downloads[0].progress_pct - 78.1).abs() < 0.2);

        id: 10,

    assert!(state.downloads.is_empty());
    assert_eq!(state.selected_id, None);
}
```

```rust
//! Daemon bridge integration tests with a local mock daemon.
#![allow(clippy::unwrap_used, clippy::expect_used)]

use axum::extract::ws::{Message as AxumWsMessage, WebSocket, WebSocketUpgrade};
use axum::extract::State;
use axum::http::StatusCode;
use axum::response::IntoResponse;
use axum::routing::{get, post};
use axum::{Json, Router};
use futures_util::{SinkExt, StreamExt};
use odm_api::{AddDownloadRequest, AddDownloadResponse, DownloadItemDto, Event, HealthResponse, ListDownloadsResponse, WsAuthRequest, WsAuthResponse};
use odm_gui::bridge::DaemonBridge;
use odm_gui::messages::{GuiEvent, UserAction};
use std::sync::Arc;
use std::time::Duration;
use tokio::net::TcpListener;
use tokio::sync::mpsc;

#[tokio::test]
async fn bridge_connects_syncs_downloads_and_forwards_events() {
    let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
    let addr = listener.local_addr().unwrap();

    let app = Router::new()
        .route(
            "/api/v1/health",
            get(|| async {
                Json(HealthResponse {
                    status: "ok".to_string(),
                    version: "0.1.0".to_string(),
                })
            }),
        )
        .route(
            "/api/v1/downloads",
            get(|| async {
                Json(ListDownloadsResponse {
                    downloads: vec![DownloadItemDto {
                        id: 1,
                        url: "http://127.0.0.1/test.bin".to_string(),
                        filename: "test.bin".to_string(),
                        state: "downloading".to_string(),
                        total_bytes: Some(1024),
                        downloaded_bytes: 512,
                        progress_pct: 50.0,
                        speed_bps: 100,
                        queue: "default".to_string(),
                        target_dir: "/tmp".to_string(),
                        error: None,
                    }],
                })
            }),
        )
        .route(
            "/api/v1/events",
            get(|ws: WebSocketUpgrade| async move {
                ws.on_upgrade(|mut socket| async move {
                    if let Some(Ok(AxumWsMessage::Text(msg))) = socket.next().await {
                        if let Ok(req) = serde_json::from_str::<WsAuthRequest>(&msg) {
                            if req.token == "test-token" {
                                let resp = serde_json::to_string(&WsAuthResponse { authenticated: true }).unwrap();
                                let _ = socket.send(AxumWsMessage::Text(resp.into())).await;

                                // Broadcast a job progress event
                                let event = Event::JobProgress {
                                    id: 1,
                                    downloaded_bytes: 1024,
                                    total_bytes: Some(1024),
                                    speed_bps: 200,
                                };
                                let evt_json = serde_json::to_string(&event).unwrap();
                                let _ = socket.send(AxumWsMessage::Text(evt_json.into())).await;
                            }
                        }
                    }
                })
            }),
        );

    tokio::spawn(async move {
        axum::serve(listener, app).await.unwrap();
    });

    let (ui_tx, mut ui_rx) = mpsc::unbounded_channel::<GuiEvent>();
    let (action_tx, action_rx) = mpsc::unbounded_channel::<UserAction>();

    let server_url = format!("http://{addr}");
    let _bridge = DaemonBridge::start(server_url, Some("test-token".to_string()), ui_tx, action_rx);

    // Verify initial connection and download list event received
    let mut got_connected = false;
    let mut got_downloads = false;
    let mut got_progress = false;

    for _ in 0..30 {
        if let Ok(event) = tokio::time::timeout(Duration::from_millis(100), ui_rx.recv()).await {
            match event {
                Some(GuiEvent::DaemonStatus(true)) => got_connected = true,
                Some(GuiEvent::DownloadsList(list)) => {
                    if !list.is_empty() && list[0].id == 1 {
                        got_downloads = true;
                    }
                }
                Some(GuiEvent::EngineEvent(Event::JobProgress { id, downloaded_bytes, .. })) => {
                    if id == 1 && downloaded_bytes == 1024 {
                        got_progress = true;
                    }
                }
                _ => {}
            }
            if got_connected && got_downloads && got_progress {
                break;
            }
        }
    }

    assert!(got_connected, "Bridge did not report daemon connection");
    assert!(got_downloads, "Bridge did not load initial downloads");
    assert!(got_progress, "Bridge did not forward websocket progress event");
}
```

```rust
#![allow(clippy::unwrap_used, clippy::expect_used)]

use odm_api::{AddDownloadRequest, DownloadItemDto, Event, ProbeResponse};
use odm_gui::messages::{GuiEvent, UserAction};
use odm_gui::state::{Filter, ThemeMode, ViewState};

#[test]
fn full_gui_lifecycle_flow() {
    let mut state = ViewState::default();

    // 1. User copies URL, clipboard emits URL captured event
    state.apply_event(GuiEvent::UrlCaptured("http://127.0.0.1:8080/sample.tar.gz".to_string()));
    assert!(state.add_dialog.open);
    assert_eq!(state.add_dialog.url, "http://127.0.0.1:8080/sample.tar.gz");

    // 2. Probe returns metadata
    state.apply_event(GuiEvent::ProbeResult(Ok(ProbeResponse {
        backend: "http".to_string(),
        filename: Some("sample.tar.gz".to_string()),
        size: Some(10_000_000),
        ranges: true,
        etag: Some("w/123".to_string()),
        last_modified: None,
    })));
    assert_eq!(state.add_dialog.filename, "sample.tar.gz");

    // 3. User submits download
    state.close_add_dialog();

    // 4. Daemon confirms download added
    let item = DownloadItemDto {
        id: 42,
        url: "http://127.0.0.1:8080/sample.tar.gz".to_string(),
        filename: "sample.tar.gz".to_string(),
        state: "downloading".to_string(),
        total_bytes: Some(10_000_000),
        downloaded_bytes: 0,
        progress_pct: 0.0,
        speed_bps: 0,
        queue: "default".to_string(),
        target_dir: "C:\\Downloads".to_string(),
        error: None,
    };
    state.apply_event(GuiEvent::EngineEvent(Event::JobAdded(item)));
    assert_eq!(state.downloads.len(), 1);
    assert_eq!(state.downloads[0].id, 42);

    // 5. Select item and update progress
    state.select_download(Some(42));
    assert_eq!(state.selected_id, Some(42));

    state.apply_event(GuiEvent::EngineEvent(Event::JobProgress {
        id: 42,
        downloaded_bytes: 5_000_000,
        total_bytes: Some(10_000_000),
        speed_bps: 1_000_000,
    }));
    assert_eq!(state.downloads[0].downloaded_bytes, 5_000_000);
    assert_eq!(state.downloads[0].progress_pct, 50.0);

    // 6. Complete job
    state.apply_event(GuiEvent::EngineEvent(Event::JobStateChanged {
        id: 42,
        state: "completed".to_string(),
    }));
    assert_eq!(state.downloads[0].state, "completed");

    // 7. Verify filtering
    state.filter = Filter::Active;
    assert!(state.filtered_downloads().is_empty());
    state.filter = Filter::Completed;
    assert_eq!(state.filtered_downloads().len(), 1);

    // 8. Delete job
    state.apply_event(GuiEvent::EngineEvent(Event::JobRemoved(42)));
    assert!(state.downloads.is_empty());
    assert_eq!(state.selected_id, None);
}
```
