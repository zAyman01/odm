> **For agentic workers:** Do the tasks in order, one at a time, every step in order. Tick each checkbox as you finish it. If a command's output does not match the "Expected" line, stop and report; do not work around it.

**Goal:** A tested core that represents download jobs, enforces the state machine, persists jobs in SQLite, and downloads a file from a local HTTP server in one stream.

**Architecture:** `odm-core` gains the domain model (`Job`, `JobState`, `Source`, `JobOptions`), a SQLite repository with numbered migrations, the `Backend` trait and its control/progress context, an HTTP backend, and a minimal `Engine` that probes, runs and persists one job. //! State machine tests for the job lifecycle.
#![allow(clippy::unwrap_used, clippy::expect_used)]

use odm_core::{Job, JobOptions, JobState, Source};

const QUEUED: &[JobState] = &[JobState::Probing, JobState::Paused, JobState::Cancelled];
const PROBING: &[JobState] = &[
    JobState::Downloading,
    JobState::Failed,
    JobState::Paused,
    JobState::Cancelled,
];
const DOWNLOADING: &[JobState] = &[
    JobState::Paused,
    JobState::Verifying,
    JobState::Seeding,
    JobState::Completed,
    JobState::Failed,
    JobState::Cancelled,
];
const PAUSED: &[JobState] = &[JobState::Queued, JobState::Cancelled];
const VERIFYING: &[JobState] = &[JobState::Completed, JobState::Failed];
const SEEDING: &[JobState] = &[JobState::Completed, JobState::Paused, JobState::Cancelled];
const FAILED: &[JobState] = &[JobState::Queued, JobState::Cancelled];

fn allowed(from: JobState) -> &'static [JobState] {
    match from {
        JobState::Queued => QUEUED,
        JobState::Probing => PROBING,
        JobState::Downloading => DOWNLOADING,
        JobState::Paused => PAUSED,
        JobState::Verifying => VERIFYING,
        JobState::Seeding => SEEDING,
        JobState::Failed => FAILED,
        JobState::Completed | JobState::Cancelled => &[],
    }
}

fn new_job() -> Job {
    Job::new(
        Source::Url("https://example.com/file.bin".to_string()),
        std::env::temp_dir(),
        JobOptions::default(),
    )
}

#[test]
fn state_machine_matches_the_spec_table() {
    for from in JobState::ALL {
        for to in JobState::ALL {
            assert_eq!(
                from.can_transition_to(to),
                allowed(from).contains(&to),
                "{from:?} -> {to:?}"
            );
        }
    }
}

#[test]
fn transition_to_updates_the_job() {
    let mut job = new_job();
    assert_eq!(job.state(), JobState::Queued);

    job.transition_to(JobState::Probing).unwrap();
    assert_eq!(job.state(), JobState::Probing);

    job.transition_to(JobState::Downloading).unwrap();
    assert_eq!(job.state(), JobState::Downloading);
}

#[test]
fn invalid_transition_is_rejected_and_state_is_unchanged() {
    let mut job = new_job();
    assert!(job.transition_to(JobState::Completed).is_err());
    assert_eq!(job.state(), JobState::Queued);
}

#[test]
fn completed_and_cancelled_are_final() {
    for terminal in [JobState::Completed, JobState::Cancelled] {
        for next in JobState::ALL {
            assert!(
                !terminal.can_transition_to(next),
                "{terminal:?} -> {next:?}"
            );
        }
    }
}

pub(crate) fn now_millis() -> i64 {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|duration| duration.as_millis().min(i64::MAX as u128) as i64)

}

}
impl JobState {
    pub const ALL: [Self; 9];
    pub fn can_transition_to(self, next: Self) -> bool;
    pub fn transition_to(self, next: Self) -> Result<Self, TransitionError>;
}

pub struct TransitionError { pub from: JobState, pub to: JobState }

pub enum Source { Url(String), Magnet(String), TorrentFile(PathBuf) }
impl Source { pub fn url(&self) -> Option<&str>; }

pub enum BackendKind { Http, Torrent, Hls, Dash, YtDlp, Plugin }

}

impl Job {
    pub fn new(source: Source, target_dir: PathBuf, options: JobOptions) -> Self;
    pub fn id(&self) -> JobId;
    pub fn source(&self) -> &Source;
    pub fn filename(&self) -> &str;
    pub fn target_dir(&self) -> &Path;
    pub fn state(&self) -> JobState;
    pub fn backend(&self) -> BackendKind;
    pub fn total_bytes(&self) -> Option<u64>;
    pub fn downloaded_bytes(&self) -> u64;
    pub fn supports_ranges(&self) -> bool;
    pub fn etag(&self) -> Option<&str>;
    pub fn last_modified(&self) -> Option<&str>;
    pub fn content_type(&self) -> Option<&str>;
    pub fn error(&self) -> Option<&JobErrorInfo>;
    pub fn options(&self) -> &JobOptions;
    pub fn created_at(&self) -> i64;
    pub fn updated_at(&self) -> i64;
    pub fn target_path(&self) -> PathBuf;
    pub fn part_path(&self) -> PathBuf;
    pub fn transition_to(&mut self, next: JobState) -> Result<(), TransitionError>;
    pub fn apply_probe(&mut self, probe: ProbeResult);
    pub fn set_backend(&mut self, backend: BackendKind);
    pub fn set_downloaded_bytes(&mut self, bytes: u64);
    pub fn set_error(&mut self, message: impl Into<String>, retryable: bool);
    pub fn clear_error(&mut self);
}

Behavior rules:

- `JobState::ALL` lists the nine states in the order of the spec table.
- The transition table is exactly section 3 of the spec. `Completed` and `Cancelled` have no outgoing transitions.
- `TransitionError` implements `std::error::Error` and `Display` through `thiserror`.
- `Job::new` starts `Queued`, `BackendKind::Http`, empty filename, zero bytes, no error, and sets both timestamps with `now_millis`.
- `target_path()` uses `target_dir.join(filename)`, or `download` when filename is empty. `part_path()` appends `.part` to the effective filename.
- `transition_to` validates before mutating, updates `updated_at`, and leaves the job untouched on error.
- `apply_probe` copies backend, filename (only when the job has no filename yet), size, range support, ETag, Last-Modified and content type, and updates `updated_at`.
- `set_downloaded_bytes`, `set_error` and `clear_error` update `updated_at`.
- Implement `Serialize`/`Deserialize` for `JobState`, `BackendKind`, `Source` and `JobOptions` with `serde`; use `snake_case` names.
- Add `pub(crate) struct JobRecord` and `pub(crate) fn from_record(record: JobRecord) -> Self` for the store in Task 2. Do not expose a public state setter.

impl Store {

    pub fn open_in_memory() -> Result<Self, StoreError>;

Implementation rules:

- Use `std::sync::Mutex<Connection>`. Never hold the guard across an `.await`.
- `Store::open` creates the parent directory when it is non-empty, opens the database, enables `PRAGMA foreign_keys = ON` and `PRAGMA busy_timeout = 5000`, and applies migrations.
- `schema_migrations` has `version INTEGER PRIMARY KEY` and `applied_at INTEGER NOT NULL`.
- Migration 1 creates `jobs` and an index on `state`:

```sql
CREATE TABLE jobs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    source_json TEXT NOT NULL,
    filename TEXT NOT NULL,
    target_dir TEXT NOT NULL,
    state TEXT NOT NULL,
    backend TEXT NOT NULL,
    total_bytes INTEGER,
    downloaded_bytes INTEGER NOT NULL DEFAULT 0,
    supports_ranges INTEGER NOT NULL DEFAULT 0,
    etag TEXT,
    last_modified TEXT,
    content_type TEXT,
    error_message TEXT,
    error_retryable INTEGER NOT NULL DEFAULT 0,
    options_json TEXT NOT NULL,
    created_at INTEGER NOT NULL,
    updated_at INTEGER NOT NULL
);
CREATE INDEX idx_jobs_state ON jobs(state);
```

- Apply each numbered migration inside a transaction and record it in `schema_migrations`. Reopening a database must not re-apply migration 1.
- Store `Source` and `JobOptions` as JSON; store timestamps and byte counts as SQLite `INTEGER` (`i64`); store booleans as `0` or `1`.
- `insert_job` inserts all fields, then sets the job's id from `last_insert_rowid()`.
- `get_job` returns `StoreError::JobNotFound` when no row matches. `update_job` also returns `JobNotFound` when the update affects zero rows.
- `list_jobs` orders by `id ASC`.
- Parse stored state and backend names back into the enums; unknown values return `InvalidState` or `InvalidBackend`.
- Update `crates/odm-core/src/lib.rs` to declare `pub mod store;` and re-export `Store` and `StoreError`.

//! HTTP probe and single-stream download tests against a local server.
#![allow(clippy::unwrap_used, clippy::expect_used)]

use std::net::SocketAddr;
use std::sync::Arc;

use axum::body::Body;
use axum::extract::State;
use axum::http::{header, HeaderMap, HeaderValue, Method, StatusCode};
use axum::response::{IntoResponse, Response};
use axum::routing::{any, get};
use axum::Router;
use odm_core::{
    Backend, BackendKind, ControlToken, HttpBackend, Job, JobContext, JobOptions, ProgressSink,
    RunOutcome, Source,
};
use tempfile::TempDir;
use tokio::net::TcpListener;

const PAYLOAD: &[u8] = b"odm single stream test payload";

struct TestServer {
    addr: SocketAddr,
    handle: tokio::task::JoinHandle<()>,
}

impl TestServer {
    async fn start() -> Self {
        let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
        let addr = listener.local_addr().unwrap();
        let app = Router::new()
            .route("/file.bin", get(file))
            .route("/named.bin", get(named))
            .route("/head-405.bin", any(no_head))
            .route("/range-405.bin", any(range))
            .with_state(Arc::new(PAYLOAD.to_vec()));
        let handle = tokio::spawn(async move {
            axum::serve(listener, app).await.unwrap();
        });
        Self { addr, handle }
    }

    fn url(&self, path: &str) -> String {
        format!("http://{}{}", self.addr, path)
    }
}

impl Drop for TestServer {
    fn drop(&mut self) {
        self.handle.abort();
    }
}

async fn file(State(payload): State<Arc<Vec<u8>>>) -> Response {
    response(&payload, None, None)
}

async fn named(State(payload): State<Arc<Vec<u8>>>) -> Response {
    response(
        &payload,
        Some("attachment; filename=\"report.pdf\""),
        Some("\"abc\""),
    )
}

async fn no_head(method: Method, State(payload): State<Arc<Vec<u8>>>) -> Response {
    if method == Method::HEAD {
        (StatusCode::METHOD_NOT_ALLOWED, [(header::ALLOW, "GET")]).into_response()
    } else {
        response(&payload, None, None)
    }
}

async fn range(
    method: Method,
    headers: HeaderMap,
    State(payload): State<Arc<Vec<u8>>>,
) -> Response {
    if method == Method::HEAD {
        return (StatusCode::METHOD_NOT_ALLOWED, [(header::ALLOW, "GET")]).into_response();
    }
    if headers.get(header::RANGE).and_then(|value| value.to_str().ok()) == Some("bytes=0-0") {
        let mut headers = HeaderMap::new();
        headers.insert(
            header::CONTENT_RANGE,
            HeaderValue::from_str(&format!("bytes 0-0/{}", payload.len())).unwrap(),
        );
        headers.insert(header::CONTENT_LENGTH, HeaderValue::from_static("1"));
        headers.insert(header::ACCEPT_RANGES, HeaderValue::from_static("bytes"));
        return (StatusCode::PARTIAL_CONTENT, headers, Body::from(payload[0..1].to_vec()))
            .into_response();
    }
    response(&payload, None, None)
}

fn response(payload: &[u8], disposition: Option<&str>, etag: Option<&str>) -> Response {
    let mut headers = HeaderMap::new();
    headers.insert(
        header::CONTENT_TYPE,
        HeaderValue::from_static("application/octet-stream"),
    );
    headers.insert(
        header::CONTENT_LENGTH,
        HeaderValue::from_str(&payload.len().to_string()).unwrap(),
    );
    if let Some(value) = disposition {
        headers.insert(
            header::CONTENT_DISPOSITION,
            HeaderValue::from_str(value).unwrap(),
        );
    }
    if let Some(value) = etag {
        headers.insert(header::ETAG, HeaderValue::from_str(value).unwrap());
    }
    (StatusCode::OK, headers, Body::from(payload.to_vec())).into_response()
}

Implementation rules:

- Only `Source::Url` is accepted; other sources return `BackendError::Unsupported`. Parse with `url::Url`; a parse failure is `BackendError::InvalidUrl`.
- Apply `JobOptions` to every request: extra headers, user agent, referer and cookies. Invalid header names or values return `BackendError::InvalidOptions`; do not include header values in error messages.

- `run` sends `GET`, rejects a non-success status with `BackendError::Status`, creates the target directory, and writes to `job.part_path()`.

Behavior rules:

- `Engine::new` builds `HttpBackend::new()` and stores it with the `Store`.
- `add` parses the URL with `url::Url`; only `http` and `https` are accepted. It creates `Job::new(Source::Url(url.to_string()), target_dir, options)`, sets `BackendKind::Http`, inserts the job, and returns it.
